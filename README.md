## Описание

To-Do List, перенесённый на TypeScript. Проект использует Vue 3 + Vite, Pinia и Vue Router. Настроены ESLint (flat config) и Prettier. Сохранены все функции из лабораторной №7: регистрация, вход, разделение задач по пользователям, поиск, модалка и темы.

## Установка

```bash
npm ci
```
